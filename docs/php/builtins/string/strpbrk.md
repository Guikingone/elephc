## strpbrk()

```php
function strpbrk(string $string, string $characters): mixed
```

Lowers `strpbrk(string, characters)` and boxes its `string|false` result as Mixed.

**Parameters**:
- `$string` (`string`)
- `$characters` (`string`)

**Returns**: `mixed`
