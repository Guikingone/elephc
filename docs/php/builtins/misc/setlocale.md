## setlocale()

```php
function setlocale(int $category, string $locales, ...$rest): mixed
```

Lowers `setlocale($category, $locale, ...)` as a minimal sound stub.

**Parameters**:
- `$category` (`int`)
- `$locales` (`string`)
- `...$rest` — variadic: collects excess arguments into `$rest`.

**Returns**: `mixed`
